# Changelog

## 2.0.0 - measurement-engine release candidate

- Added three independent graph configurations and persistent current/preset state.
- Added horizontal/vertical pinch zoom, persistent cursor, maximize and double-tap reset.
- Added user-defined Y/frequency limits, grid spacing and per-window smoothing/averaging.
- Added dedicated precision measurement capture with 1/48-octave base storage.
- Added energy-domain time averaging, transient rejection and capture-time accounting.
- Added trace visibility, rename/delete, equal-energy spatial averaging and session persistence/recovery.
- Added explicit input selection and routed-input reporting.
- Added multiple phone calibration profiles, manufacturer reference-mic calibration import, reference-match Auto Cal and verification.
- Added separate one-point SPL level calibration.
- Added orientation metadata/warnings and landscape operation.
- Changed package ID to app.precisionrta.v2 to coexist with V1 during field testing.
